# 段落, 换行, 水平线

## 段落标签

段落是通过 `<p>` 标签定义的

```html
<p>这是一个段落</p>
<p>这是另一个段落</p>
```

使用 `<p>` 包裹可以让我们方便地调整大小和样式等

## 换行标签

如果希望在不产生一个新段落的情况下进行换行, 使用 `<br>` 标签

`<br>` 标签是一个单标签

```html
<p>这个<br>段落<br>演示了分行</p>
```

## 水平线标签

`<hr/>` 标签在 HTML 界面中创建水平线

注意它是一个单标签

```html
<hr color="" width="" size="" align=""/>
```

**相关属性**

- color: 颜色
- width: 长度
- size: 线条粗细
- align: 对齐方式, default center
