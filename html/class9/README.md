# 表格

表格在数据展示方面非常简单， 并且表现优秀

## 表格的组成与特点

行， 列， 单元格

单元格特点: 同行等高， 同列等宽

## 表格标签

- 表格: `<table>`
- 行: `<tr>`
- 单元格(列) `<td>`

**示例**

```html
<table>
    <tr>
        <td>黑马程序员</td>
        <td>百战程序员</td>
    </tr>
    <tr>
        <td>阿里云</td>
        <td>腾讯云</td>
    </tr>
</table>
```

## 属性

table 属性

- `border`: 设置表格的边框
- `width`: 宽度
- `height`: 高度
