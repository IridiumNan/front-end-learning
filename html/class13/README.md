# 内联元素和块元素

内联元素和块元素 的 区别

| 块级元素 | 内联元素 |
| --- | --- |
|块元素会在页面中独占一行| 行内元素不会独占页面中的一行|
|可以设置 width, height 属性 | 行内设置 width, height 属性无效|
|一般块级元素可以包含行内元素和其他块级元素| 一般内联元素不包含块级元素|

常见块级元素

`div` `form` `h1~h6` `hr` `p` `table` `ul` etc...

常见内联元素

`a` `b` `em` `i` `span` `strong`

行内块级元素 (不换行， 能够识别宽高)

`button` `img` `input`
