# 超链接标签

## 超链接描述

HTML 使用标签 `<a>` 来设置超文本链接

超链接可以是一个字， 一个词， 或者一组词， 可以点击这些内容来跳转到新的文档或者当前文档的某个部分

```html
<a href="https://www.waterman.xin">Waterman 网址</a>
```

**属性**

在标签 `<a>` 中使用 `href` 属性来描述链接的地址

***href 当中的内容必须是一个完整的链接 或 当前文档的相对路径***

展示的形式

1. 一个尚未访问过的链接显示为蓝色字体并带有下划线
2. 访问过的链接显示为紫色并带有下划线
3. 点击链接时， 链接显示为红色并带有下划线

> [!NOTE]
> 可以使用 css 样式修改这些效果
