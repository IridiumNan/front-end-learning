# Form 表单

表单在 Web 网页中用来给用户填写信息, 从而能够采集用户信息， 使得网页具有交互的功能

所有的用户输入内容都是用表单来填写， 如登录注册， 搜索框等

表单是由容器和控件组成的， 一个表单一般应该包含用户填写信息的输入框， 提交按钮等， 这些输入框， 按钮叫做控件， 表单是容器， 它可以容纳各种各样的控件

---

```html
<form action="url" method="get|post" name="myform"></form>
```

> [!NOTE]
> 属性说明  
> `action` 服务器地址  
> `name` 表单名称

## 表单元素

一个完整的表单包含三个基本组成部分: 表单标签, 表单域， 表单按钮

- 表单标签
- 表单域
- 表单按钮

```html
<form>
    <input type="text">
    <input type="submit">
</form>
```
