# 关系选择器

**分类**

- 后代选择器
- 子代选择器
- 相邻兄弟选择器
- 通用兄弟选择器

## 后代选择器

### 定义

选择所有被 E 元素包含的 F 元素， 中间用空格隔开

### 语法

```css
E F{rules...}
```

案例

```css
#origin p {
    color: red;
}
```

## 子代选择器

### 定义

选择所有所谓 E 元素的直接子元素 F, 对更深一层的元素不起作用, 用 `>` 表示

### 语法

```css
E>F{rules...}
```

案例

```css
#father>p {
    color: blue;
}
```

## 相邻兄弟选择器

### 定义

紧跟 E 元素后的 F 元素， 用加号表示， 选择相邻的第一个元素元素, 用 `+` 隔开

### 语法

```css
E+F{rules...}
```

案例

```css
#brother+p {
    color: blue;
}
```

## 通用兄弟选择器

### 定义

选择 E 元素之后的所有兄弟元素 F, 作用于多个元素， 用 `~` 隔开, **只能向下选择**

### 语法

```css
E~F{rules...}
```

案例

```css
#leader~p {
    color: purple;
}
```
