# 选择器二

## ID 选择器

针对某一个特定的标签来使用， ***原则上只能使用一次***. `css` 当中的 `ID选择器` 使用 `#` 来定义

如果有使用同一个样式来标识不同元素的需求， 使用 `class`

```css
#mytitle{
    border: 3px dashed green;
}
```

```html
<h2 id="mytitle">你好</h2>
```

> [!NOTE]
> ID 是唯一的<br>
> ID 不能以数字开头

## 合并选择器

语法: `选择器1， 选择器2, ... {}`

作用: 提取共同的样式， 减少重复代码

```css
.header .footer{
    height: 300px;
}
```

## 选择器的优先级

现有的选择器

- 全局选择器: `*`
- 元素选择器: 标签名称
- 类选择器: `.className`
- ID选择器: `.IDName`

**优先级**

CSS 中， 优先级权重使用数字衡量

元素选择器: 1
class 选择器: 10
id 选择器: 100
内联样式选择器: 1000

优先级从高到低: 行内样式, ID, class, element

> [!NOTE]
> 对于同一个级别， 后指定的样式会覆盖原有的样式
