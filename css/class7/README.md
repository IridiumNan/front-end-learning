# 文本属性

## text-align

指定元素文本的水平对齐方式

| value | decription |
| --- | --- |
| `left` | 文本居左排列， 默认值 |
| `center` | 文本居中 |
| `right` | 文本居右 |

示例

```css
h1{text-align: center;}
h2{text-align: left;}
h3{text-align: right;}
```

## text-decoration

规定添加到文本的修饰, 下划线， 上划线， 删除线等

| value | decription |
| --- | --- |
| `underline` | 下划线 |
| `overline` | 上划线 |
| `line-through` | 删除线 |

```css
h1{text-decoration: overline;}
h2{text-decoration: underline;}
h3{text-decoration: line-through;}
```

## text-transform

控制文本大小写

| value | decription |
| --- | --- |
| `capitalize` | 单词首字母大写 |
| `lowercase` | 所有字母都小写 |
| `uppercase` | 所有字母都大写 |

```css
h1{text-transform: uppercase;}
h2{text-transform: capitalize;}
p {text-transform: lowercase;}
```

## text-indent

规定本快当中的首行文本缩进

```css
p{text-indent: 50px;}
```
