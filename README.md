# 前端学习仓库

[bilibili 教程网址](https://www.bilibili.com/video/BV1gCh168Ena?t=4.5)

## 运行

```bash
python -m http.server 8080

# or you can run the start.sh script if you use Linux or macOS
./start.sh
# It will start a python file server on port 8080
```

> [!NOTE]
> 运行之后访问 <http://127.0.0.1:8080/> 即可<br>
> 如果使用的是服务器， 那么改成服务器的ip地址
