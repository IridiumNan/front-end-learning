# Element 获取元素位置

| attribute | description |
| -- | -- |
| clientHeight | 获取元素高度 包括 `padding` 部分， 不包括 `border` `margin` |
| clientWidth | 获取元素宽度包括 `padding` 部分， 不包括 `border` `margin` |
| scrollLeft | 元素的水平滚动条向右滚动的像素距离 |
| scrollTop | 元素的垂直滚动条向下滚动的像素距离 |
| offsetHeight | 元素的 CSS 垂直高度, 包括元素本身的高度, padding 和 border |
| offsetWidth | 元素的 CSS 水平宽度, 包括元素本身的高度, padding 和 border |
| offsetLeft | 到定位父级左边界的间距 |
| offsetTop | 到定位父级上边界的间距 |
