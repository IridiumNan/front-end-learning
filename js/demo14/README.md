# 鼠标事件

| event | desc |
| -- | -- |
| `click` | 按下鼠标同时触发 |
| `dblclick` | 在同一个元素上双击鼠标时触发 |
| `mousedown` | 按下鼠标键时触发 |
| `mouseup` | 松开鼠标键时触发 |
| `mousemove` | 当鼠标指针在节点内部移动时出发， 鼠标连续移动时， 该事件会连续触发 |
| `mouseenter` | 鼠标进入一个节点时触发 |
| `mouseleave` | 鼠标离开一个节点时出发 |
| `mouseover` | 鼠标进入一个节点时触发， 进入子节点会再次触发这个事件 |
| `mouseout` | 鼠标离开一个节点时出发， 离开父节点会再次触发这个事件 |
| `wheel` | 滚动鼠标的滚轮时触发 |
