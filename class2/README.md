# 标题标签

## 标题的介绍与应用

标题 (Heading) 是通过 `<h1> - <h6>` 标签进行定义的.

`<h1>` 定义最大的一级标题， `<h6>` 定义最小的六级标题

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
...
<h6>六级标题</h6>
```

## 标题位置摆放

在标签中添加属性: `align='left center right'`, default left

```html

<h2 align='center'>中间对齐</h2>

<h2 align='right'>右对齐</h2>
```
